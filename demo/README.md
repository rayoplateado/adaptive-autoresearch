# Demo: Simulated Session

This demo shows what a full adaptive-autoresearch session looks like when
run against a React + Tailwind + shadcn frontend project. All outputs are
simulated — no actual project was harmed in the making of this demo.

The fictional project is a **SaaS analytics dashboard** with:
- React 19 + Vite + TypeScript
- Tailwind CSS v4 + shadcn/ui
- Convex backend
- No tests, vibecoded by a solo founder

The files below simulate each phase of the loop.

## Files

| File | What it shows |
|---|---|
| `session.md` | The living session document after 15 iterations |
| `fitness.yaml` | The composed fitness profile with all 5 metric types |
| `session.jsonl` | Selected iteration log entries |
| `plan.yaml` | The execution plan with issue groups |
